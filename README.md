# 5학년 3반 이야기

학급 소식을 전하는 블로그예요. 모든 글과 담임 연락처는 `posts.json` 파일 하나에 들어 있어요.
이 파일을 고치면 1~2분 뒤 모든 학부모님 화면에 반영돼요. 첫 화면에는 날짜가 최신인 글 3개가 자동으로 올라와요.

## 새 글 올리기 (추천 방법)

1. 블로그 주소 끝에 `?write`를 붙여 열어요. 예: `https://아이디.github.io/저장소이름/?write`
2. **＋ 새 글 쓰기**를 눌러 분류, 날짜, 제목, 내용을 적고 **올리기**를 눌러요.
3. 화면에 나온 **전체 복사**를 누르고, **GitHub에서 posts.json 편집 열기**를 눌러요.
4. 원래 내용을 모두 지우고(Ctrl+A) 붙여넣은 다음 **Commit changes**를 눌러요.

`?write` 화면에서는 글 삭제와 연락처 수정도 같은 방법으로 할 수 있어요.
이 화면은 새 내용을 만들어 보여 주기만 해요. 그래서 다른 사람이 주소를 알아도 블로그를 바꿀 수 없어요.

## 사진 넣기

1. GitHub 저장소에서 `images` 폴더를 열고 **Add file → Upload files**로 사진을 올려요.
   사진 파일 이름은 영어와 숫자로 짓는 게 좋아요(예: `sports-day.jpg`).
2. 글을 쓸 때 **사진 파일 이름** 칸에 그 이름을 적어요.

## posts.json을 직접 고칠 때

- `category`(분류): `news` = 학급 소식, `photo` = 사진첩, `notice` = 알림장
- `date`(날짜): `2026-10-22`처럼 적어요.
- `body`(내용): 줄을 바꾸려면 `\n`을 넣어요.
- `"example": true`가 붙은 글에는 '예시 글' 표시가 나와요. 처음에 들어 있는 예시 글 3개는 지워 주세요.
- 항목 사이의 쉼표(,)와 따옴표(")가 하나라도 빠지면 글 목록이 안 보여요.

## 내 컴퓨터에서 미리 보기

`index.html`을 더블클릭해 열면 글 목록이 보이지 않아요. 브라우저가 내 컴퓨터의 `posts.json`을 읽지 못하게 막기 때문이에요.
이 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000`을 열어 주세요.

```
python -m http.server 8000
```
